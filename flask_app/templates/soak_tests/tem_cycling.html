🔄 TEM Disk Cycling Test

Test Description

This test performs bidirectional TEM disk cycling between clean (TC) and used (TE) positions.

Cycle definition: All 10 disks moved TC→TE + all returned TE→TC = 1 complete cycle

Process: Pick → laser detect → place (with separate X/Y movement to avoid contamination)
