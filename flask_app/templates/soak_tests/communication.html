📡 Communication Stress Test

Test Description

This test evaluates communication reliability with the PLC and/or robot at progressively faster speeds. Commands are sent at intervals from 1.0s down to 0.1s, measuring response times and failure rates.

Speed progression: 1.0s → 0.8s → 0.6s → 0.4s → 0.2s → 0.1s intervals

Batch size: 25 commands per speed level
